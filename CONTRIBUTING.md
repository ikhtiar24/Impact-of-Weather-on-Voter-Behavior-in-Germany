# Contributing Guidelines

Thank you for your interest in contributing to this project!

## How to Contribute

- **Report issues** clearly and concisely. Include steps to reproduce bugs or a detailed description of suggestions or problems.
- **Submit a Merge Request (Pull Request)** if you would like to contribute code. Please create a separate feature branch with a descriptive name and provide a short summary of your changes.
- For significant changes, open an issue first to discuss your idea with the maintainers.

## Community Standards

We ask all contributors to:

- Be respectful and inclusive in all communications (see our [Code of Conduct](./CONDUCT.md)).
- Keep commits focused and well-explained.
- Provide constructive feedback and be open to it from others.

## Additional Resources

- For general questions, please use the issue tracker.
- For larger proposals, please consult with the team via an issue before starting development.

We appreciate your contributions and collaboration!
